Why the binary is not rebuilt from source here
----------------------------------------------
Campfire's published repository does not contain every source file its own sources reference
(namespaces Campfire.Mods and Campfire.Link.Lobby are used but absent at branch main), so the program
cannot be rebuilt from that repository as it stands. Distributing the upstream release binary unchanged,
together with this notice and the licence, is the compliant way to ship it.
