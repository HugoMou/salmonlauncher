01 —

Capabilities

Six areas, one window

Not a web wrapper: from the version manifest to the game process, every layer runs inside one local application.

01 INSTALL

Versions & loaders

Official Mojang manifests plus Fabric, Quilt, Forge and NeoForge. Mirror fallback, resume, and a SHA-1 check on every last file.

02 LAUNCH

A pipeline you can watch

Metadata, libraries, natives, assets, Java and arguments — each step reported live, instead of a frozen window and a prayer.

03 MODS

Instances stay isolated

Per-instance mods, resource packs, shaders, saves and logs. Toggling a mod renames the extension — your files never move.

04 CAMPFIRE

Multiplayer runs on Campfire

The launcher ships Campfire: enter a world and it opens to LAN with an invite code your friends can join with. The launcher can check and update Campfire in one click, downloading over multiple mirrors verified by SHA-256.

05 CATALOG

Modrinth built in

Search mods, shaders and resource packs, then install straight into the selected instance. The category picks the folder.

06 DIAGNOSE

Crashes, translated

Reads the tail of latest.log, matches known signatures, and explains the cause and the fix in plain language.

02 —

Integrity

Downloads you can audit
PIPELINE / VERIFY

Every byte has a receipt

The transfer engine does not stop at “installed”. After primary retries, mirror fallback and resume, it re-checks the file against the manifest's SHA-1 or SHA-256 — and deletes and re-downloads on a mismatch.

  • Bounded concurrency, 2–16 connections, 6–8 by default
  • Automatic full re-write when a server ignores Range
  • HTTP/1.1 plus a 60-second streaming watchdog for large overseas files
  • A source allow-list: Mojang, bmclapi2, Adoptium, GitHub and TUNA only
