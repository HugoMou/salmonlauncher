About · licence · disclaimer

A launcher you can read.

SalmonLauncher is an open-source project maintained by one person. The aim is not to have the most features, but to lay the chain of download, launch, fail and fix in front of you.

Why another launcher

Existing tools tend to split in two: ones light enough to run anywhere but which say only “launch failed”, and ones with every feature, split across pages that do not know about each other, leaving you to guess when something breaks.

This project takes a third route: every stage shares the same state, and every step is visible. Downloads carry verification records, launches report stage by stage, crashes are signature-matched, and mod toggling is just a rename.

It is built with WinUI 3 and the Windows App SDK, with a two-pane master–detail navigation and a page stack. Underneath, data, business and presentation layers depend only one way.
