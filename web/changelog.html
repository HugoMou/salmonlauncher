LATEST v2.0.5

v2.0.5

Latest 2026-11-13

Fixed several problems on the launch panel when no instance is installed.

  • Launch button fixed: with nothing to launch it stayed clickable and only explained itself afterwards. It is now disabled, states the reason on the button, and refreshes whenever the instance list or selection changes.
  • Contradictory status fixed: the panel claimed “ready” while the summary said no instance was installed. It now reports 未就绪.
  • Repeated text fixed: the same sentence appeared three times and wrapped onto two lines; the status is a single short line now.
  • The instance summary was nearly invisible in the light theme; it uses the readable secondary colour.
  • This release is installer-only; no portable build is provided.

v2.0.4

2026-11-14

Mica backdrop support, and the agreement is confirmed again when it changes.

  • Mica backdrop: with no theme wallpaper applied, the window uses the Windows 11 Mica material so the desktop shows through. An applied wallpaper still takes precedence, and Windows 10 falls back to a plain surface.
  • Agreement confirmation fixed: only “accepted” was stored, never the revision, so an updated agreement never prompted again. The accepted revision is now saved and compared.
  • This release is installer-only; no portable build is provided.

v2.0.3

2026-11-13

Unexpected errors no longer terminate the launcher.

  • No more silent exits: the global exception hook logged the error but left it unhandled, so any unexpected error still terminated the process — which is why the 2.0.2 mod-toggle crash made the launcher vanish without explanation. Recoverable exceptions are now handled, reported once through the in-app notification, and the window keeps running.
  • Error handling for operations that can fail: skin preview loading, Java rescan, opening the sign-in link, loading the install plan, and the multiplayer/update confirmation dialogs could throw outside any guard and take the process down. They now log and report instead.
  • This release is installer-only; no portable build is provided.

v2.0.2

2026-11-13

Fixed a crash when toggling mods, and mods that could not be enabled or disabled.

  • Crash fix: toggling a mod rebuilt the whole list from inside the switch's own event, destroying and recreating the control mid-operation, which crashed the XAML measure pass and terminated the process. The row is now updated in place and the status line refreshes separately.
  • Mod toggle fix: the rename used a directory move and refused to run whenever a file with the target name was left behind by an interrupted toggle, leaving the mod stuck on “target already exists” until the folder was cleaned by hand. The stale file is now removed first.
  • When a toggle fails, the switch is restored so the interface still matches the files on disk.
  • This release is installer-only; no portable build is provided.

v2.0.1

2026-11-13

Dead translation entries removed, making the package smaller; features match 2.0.0.

  • Removed 262 unused entries per language (relay, lobby, room codes, LAN scanning, companion-mod messages, obsolete terms text), dropping from 990 to 728 entries per language.
  • No displayed text changed: the removed entries were unreferenced, so deleting them cannot alter any visible string.
  • This release is installer-only; no portable build is provided.

v2.0.0

2026-11-13

The launcher gained self-update, multiplayer moved to Campfire, and the licence terms were rewritten in full.

  • Software update: check the GitHub release page under Appearance & settings → Software update, then download the installer, verify its SHA-256 and install it. Upgrading replaces program files only, keeping settings, accounts, instances and saves.
  • Update announcement: the first launch after a version change lists what changed and states that user data is kept.
  • Optional automatic update check at startup, which can be turned off and only ever notifies — nothing installs silently.
  • Multiplayer now runs the bundled Campfire as a separate program instead of an embedded window, with one-click Campfire updates over multi-source downloads verified by SHA-256.
  • Downloads use parallel ranges with mirror fallback, live speed and cancellation; the mirror-first setting now also applies when repairing files at launch.
  • The launch panel and every instance page now share one current instance and remember it; previously the two kept separate selections.
  • Fixed onboarding not recording the accepted agreement version, and the Next button being unreachable in smaller windows.
  • The user agreement grew to 13 sections with software updates, third-party copyright and redistribution duties, plus stronger disclaimers; the terms version is now 2.0.
  • Corrected descriptions of navigation paths, memory and disk usage, and loader support to match the actual behaviour.
  • This release is installer-only; no portable build is provided.

v1.0.3

2026-11-02

English-first repository, unified naming, and code signing for the installer and uninstaller.

  • The GitHub repository was renamed to salmonlauncher; the old address 301-redirects and all history and releases were kept.
  • The installer and uninstaller are now signed with a self-signed certificate (CN=SalmonLauncher, O=Hugo Mou), located automatically by the build script.
  • All four READMEs gained a download section, with the requirement unified at Windows 10 2004 (build 19041).
  • Repository-facing text, script comments and commit messages moved to English, with the brand unified as the space-free SalmonLauncher.
  • Shipped SL-Setup-1.0.3-win64.exe and SL-1.0.3-portable-win64.zip.

v1.0.2

2026-11-02

Shortcut icon fix and a fully localised setup wizard.

  • Root cause: the executable embedded no icon and the shortcut specified no icon path. Logo.ico is now embedded and referenced explicitly.
  • Desktop and Start menu shortcuts now show the application icon.
  • The setup wizard now ships in Simplified Chinese, Traditional Chinese, English and Japanese.
  • The four READMEs were bumped and gained installer and portable download notes.
